# Bandwidth Burner

ブラウザの帯域を、意味なく燃やすだけの小さなサイトです。

## 使い方

1. 「無限に消費する」を押すと、Cloudflare のダウンロードエンドポイントへ並列リクエストを開始します。
2. Mbps、転送量、経過時間、完了したリクエスト数がリアルタイムで更新されます。
3. 「10秒だけ speed test」は10秒後に自動停止します。

開始するまで通信は発生しません。モバイル回線や従量課金の接続では使わないでください。

## 開発

依存関係はありません。ローカル確認時は、ダウンロード測定が動くようHTTPサーバー経由で開いてください。

```powershell
python -m http.server 4173
```

その後、`http://localhost:4173/` を開きます。

GitHub Actions が `main` ブランチへの push を検知し、GitHub Pages へデプロイします。
